# Automated Vermicast Production Machine

## Project Overview

An ESP32-based IoT system designed to automate vermicompost production through environmental monitoring, sensor integration and automated control mechanisms.

## Technologies Used

- ESP32 Microcontroller
- Embedded C++
- Arduino IDE
- Internet of Things (IoT)
- MQTT and Wi-Fi
- RS485 and Modbus RTU
- I2C Communication

## Hardware Components

- ESP32
- Soil Moisture Sensor
- DS18B20 Temperature Sensor
- NPK Sensor
- RS485 Interface Module
- 20x4 LCD Display
- Relay Modules
- Solenoid Valve
- Amino Acid Pump
- Shredder Motor
- Vibration/Sifter Motor

## Key Features

- Real-time temperature and moisture monitoring
- Automatic irrigation control
- NPK nutrient monitoring
- Fish Amino Acid dosing
- Organic waste shredding
- Vermicompost separation
- Remote IoT monitoring
- Motor interlocking and emergency-stop input

## Required Libraries

- LiquidCrystal_I2C
- OneWire
- DallasTemperature
- PubSubClient

## Source Code Status

The firmware is a reconstructed reference implementation based on the final-year project design. Hardware calibration, configuration and validation are required before deployment.
